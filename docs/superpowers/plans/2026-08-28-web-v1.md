# Spenden-Transparenz Web v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/web`, the public donation-transparency information layer for the Nepal 2026 flood: a response board, org detail pages and trust pages, in German and English, fully static, with provenance on every displayed value and no ranking anywhere.

**Architecture:** Next.js 16 App Router, fully statically generated (`generateStaticParams` for 2 locales x 44 orgs), `use cache` + `cacheTag`, one route handler for on-demand `revalidateTag`. No client-side data fetching: board data ships in the RSC payload and is filtered synchronously in the browser over 44 rows. One shared `<Datum>` component renders every provenance-carrying value in six states; absence of data is a designed state with the same ink and weight as a found value.

**Tech Stack:** Next.js 16.3.3, React 19, TypeScript strict, Tailwind CSS 4, next-intl 4.14, shadcn 4.19 (ten components only), Radix Popover, Playwright + `@axe-core/playwright` 4.13, `@lhci/cli` 0.15, Vitest. No icon library. No chart, map or animation library.

**Spec:** `docs/superpowers/specs/2026-08-28-v1-katastrophenmodus-design.md` (section "Frontend (IA/UX)") and `apps/web/DESIGN.md`. Read both before starting. DESIGN.md is binding for tokens, the `<Datum>` contract, page skeletons and copy rules.

## Global Constraints

Every task's requirements implicitly include this section.

**Versions.** Next.js `16.3.3` (never 15 or older). next-intl `4.14.1`. shadcn CLI `4.19.0`. Tailwind `4.x`. TypeScript `strict: true`, no `any`, no `@ts-ignore`.

**Next.js 16 API facts, verified 2026-08-28.** The middleware file is `proxy.ts`, not `middleware.ts`; the export is `proxy` (next-intl's default export works). `proxy` runs on the nodejs runtime and cannot use edge. `revalidateTag` requires a **second argument** naming a `cacheLife` profile; the one-argument form is deprecated. `use cache` requires `cacheComponents: true` in `next.config.ts` and cannot appear directly in a route handler body. `setRequestLocale` is **not** used: `next/root-params` is available by default in Next 16.3+ and makes the app eligible for static rendering on its own.

**i18n.** Locales `de` (default) and `en`. `localePrefix: 'always'`. Localized pathnames per DESIGN.md section 8. One i18n namespace per work package. `messages/{de,en}/common.json` is **lead-only**; a worker who needs a key there sends a one-line request and rebases.

**File ownership.** `apps/web/**` only. Never touch `apps/api/**`, `packages/core/**`, `pipeline/**`, `data/**`, `schema/**` or root `*.md` other than the ones this plan names. `components/datum/**` and `messages/*/common.json` are lead-only; workers consume `<Datum>`, never modify it.

**Git.** Own worktree and branch per agent (`git worktree add ../st-wt-<name> <branch>` from `main`). Never work in the main checkout. **Never `git stash`** (the stash stack is shared across worktrees). PR to `main`. Merge only on green CI. LF line endings. Every commit ends with:

```

Claude-Session: https://claude.ai/code/session_018hf9r9gUZkVw4DcrongBzd
```

**Visual rules (spec, binding).** No cards. No shadows (`--shadow-*: initial` removes the utilities). No border radius except 2px on marks and filter tags (`--radius-*: initial`). No traffic-light colours. No photos of the disaster or of affected people. No tooltips for provenance (Radix Popover only). No emoji anywhere, including code, copy and logs. No uppercase headings (`text-transform` is banned). No `letter-spacing`. No em dashes in user-facing German copy; use commas or full stops.

**The one rule above all others.** "nicht gefunden" is never styled weaker than a found value: same colour token (`--ink`), same size, same weight, same position. Not muted, not italic, not smaller, not reduced opacity, not struck through.

**Never build.** Ratings, scores, grades, stars, trust badges, progress rings, meters, sorting by evidence grade, donation buttons, auth, user accounts, a map, an org-by-district matrix, AthenaRun branding, the colour `#FF6131`.

**Allowed shadcn components.** `button`, `checkbox`, `popover`, `sheet`, `input`, `badge`, `separator`, `table`, `tabs`, `dropdown-menu`. Nothing else without the lead's written approval.

**Banned shadcn components.** `card`, `accordion` (use native `<details>`), `dialog`, `alert`, `avatar`, `carousel`, `chart`, `skeleton`, `progress`, `sonner`.

**Budget.** Zero third-party network requests at runtime. Zero client-side data fetching. Board data projection <= 60 KB raw and <= 12 KB brotli. First Load JS <= 110 KB gzipped. Lighthouse mobile: Performance >= 95, Accessibility 100, Best Practices >= 95, SEO >= 95. axe: zero violations on tags `wcag2a wcag2aa wcag21a wcag21aa wcag22aa`. Breakpoints `base` / `md:768` / `xl:1280` only.

**Definition of done for every task.** The command was run, its output was read, and only then was the claim made. "It should work" is not done. Paste the command and its output into the commit or the PR body.

```js
import { readFileSync } from 'node:fs';

const css = readFileSync(new URL('../app/globals.css', import.meta.url), 'utf8');

function tokens(blockRe) {
  const block = css.match(blockRe);
  if (!block) throw new Error(`missing block: ${blockRe}`);
  const out = {};
  for (const [, k, v] of block[1].matchAll(/--([a-z-]+):\s*(#[0-9A-Fa-f]{6})/g)) out[k] = v;
  return out;
}
const lin = (c) => { c /= 255; return c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4; };
const lum = (hex) => {
  const [r, g, b] = [1, 3, 5].map((i) => parseInt(hex.slice(i, i + 2), 16));
  return 0.2126 * lin(r) + 0.7152 * lin(g) + 0.0722 * lin(b);
};
const ratio = (a, b) => {
  const [x, y] = [lum(a), lum(b)].sort((p, q) => q - p);
  return (x + 0.05) / (y + 0.05);
};

const light = tokens(/:root\s*\{([\s\S]*?)\}/);
const dark = tokens(/\.dark\s*\{([\s\S]*?)\}/);
const fails = [];
const check = (name, got, min, max = Infinity) => {
  if (got < min || got > max) fails.push(`${name}: ${got.toFixed(2)} (need ${min}..${max})`);
};

for (const [theme, t] of [['light', light], ['dark', dark]]) {
  check(`${theme} ink on bg`, ratio(t.ink, t.bg), 7);
  check(`${theme} muted on bg`, ratio(t.muted, t.bg), 4.5);
  check(`${theme} accent on bg (focus ring)`, ratio(t.accent, t.bg), 3);
  check(`${theme} warn on bg`, ratio(t.warn, t.bg), 4.5);
  const doc = ratio(t['mark-doc'], t['mark-doc-tint']);
  const open = ratio(t['mark-open'], t['mark-open-tint']);
  check(`${theme} mark-doc on tint`, doc, 4.5);
  check(`${theme} mark-open on tint`, open, 4.5);
  // DESIGN.md rule A1: "not found" must never read weaker than "documented".
  if (Math.abs(doc - open) > 0.5) {
    fails.push(`${theme} mark parity: doc ${doc.toFixed(2)} vs open ${open.toFixed(2)}, delta > 0.5`);
  }
}
if (fails.length) { console.error('CONTRAST FAILURES:\n' + fails.join('\n')); process.exit(1); }
console.log('contrast ok');
```

- [ ] **Step 3: Write the request config**

`apps/web/i18n/request.ts`. Uses `next/root-params`, which is available by default in Next 16.3+ and removes the need for `setRequestLocale`:

```ts
import * as rootParams from 'next/root-params';
import { notFound } from 'next/navigation';
import { getRequestConfig } from 'next-intl/server';
import { hasLocale } from 'next-intl';
import { routing } from './routing';

const namespaces = ['common', 'board', 'org', 'pages'] as const;

export default getRequestConfig(async ({ locale }) => {
  if (!locale) {
    const fromParams = await rootParams.locale();
    if (!hasLocale(routing.locales, fromParams)) notFound();
    locale = fromParams;
  }
  const loaded = await Promise.all(
    namespaces.map((ns) => import(`../messages/${locale}/${ns}.json`).then((m) => m.default)),
  );
  return {
    locale,
    messages: Object.fromEntries(namespaces.map((ns, i) => [ns, loaded[i]])),
    timeZone: 'Europe/Berlin',
    now: new Date('2026-08-28T14:57:00Z'),
  };
```

```ts
import type { DistrictRef } from './types';

const CODES: Record<string, string> = {
  rasuwa: 'NP0329', nuwakot: 'NP0328', dhading: 'NP0330',
  chitawan: 'NP0335', gorkha: 'NP0436', kavrepalanchok: 'NP0324', kathmandu: 'NP0327',
};
const NAMES: Record<string, string> = {
  NP0329: 'Rasuwa', NP0328: 'Nuwakot', NP0330: 'Dhading',
  NP0335: 'Chitawan', NP0436: 'Gorkha', NP0324: 'Kavrepalanchok', NP0327: 'Kathmandu',
};
// Settlements and spellings seen in the pilot data, measured 2026-08-28.
const ALIASES: Record<string, string> = {
  timure: 'NP0329', syabrubesi: 'NP0329', rasuwagadhi: 'NP0329',
  chitwan: 'NP0335', mugling: 'NP0335',
};
const NOT_A_DISTRICT = new Set(['unspecified', 'nepal', 'northern nepal', '']);

export function resolveDistrict(raw: string): DistrictRef | null {
  let k = raw.toLowerCase().trim()
    .replace(/\s*\(.*\)\s*$/, '')      // "Chitwan district (Mugling)" -> "chitwan district"
    .replace(/\s+district$/, '');
  if (NOT_A_DISTRICT.has(k) || k.startsWith('along ')) return null;
  const code = CODES[k] ?? ALIASES[k];
  if (!code) return null;
  return { code, name: NAMES[code]! };
}
```

```ts
export function formatDate(iso: string, locale: 'de' | 'en'): string {
  const d = new Date(`${iso}T00:00:00Z`);
  return new Intl.DateTimeFormat(locale === 'de' ? 'de-DE' : 'en-GB', {
    day: '2-digit', month: locale === 'de' ? '2-digit' : 'short', year: 'numeric', timeZone: 'UTC',
  }).format(d);
}
export function relativeDays(iso: string, now: Date): number {
  const a = Date.UTC(now.getUTCFullYear(), now.getUTCMonth(), now.getUTCDate());
  const b = new Date(`${iso}T00:00:00Z`).getTime();
  return Math.round((a - b) / 86_400_000);
}
export function domainOf(url: string | null): string | null {
  if (!url) return null;
  try { return new URL(url).hostname.replace(/^www\./, ''); } catch { return null; }
}
```

```ts
import type { Datum, DatumState } from '@/lib/types';
import { relativeDays } from '@/lib/format';

export function datumState(d: Datum, opts: { now: Date; staleAfterDays?: number }): DatumState {
  const staleAfter = opts.staleAfterDays ?? 30;
  if (d.value !== null) {
    if (d.verification === 'unverified') return 'value_unverified';
    if (d.retrieved_at && relativeDays(d.retrieved_at, opts.now) > staleAfter) return 'stale';
    return 'value';
  }
  switch (d.gap_reason) {
    case 'source_unreachable': return 'source_unreachable';
    case 'not_public': return 'not_public';
    default: return 'not_found';
  }
}

export function gapLabelKey(d: Datum): 'not_found' | 'not_searched' {
  return d.gap_reason === 'not_searched' ? 'not_searched' : 'not_found';
}
```

### Task 3.2: The revalidate route handler

```ts
import { revalidateTag } from 'next/cache';

export async function POST(request: Request) {
  const auth = request.headers.get('authorization');
  const expected = `Bearer ${process.env.REVALIDATE_SECRET}`;
  if (!process.env.REVALIDATE_SECRET || auth !== expected) {
    return new Response('unauthorized', { status: 401 });
  }
  const { tag } = await request.json();
  if (typeof tag !== 'string' || !/^(crisis|org):[a-z0-9-]+$/.test(tag)) {
    return new Response('bad tag', { status: 400 });
  }
  revalidateTag(tag, 'hours');   // Next 16 requires the cacheLife argument
  return Response.json({ revalidated: tag });
}
```
